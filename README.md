# خريطتي | My Map

![خريطتي: تطبيق لفهم الذات](og-image.png)

**خريطتي** مكتبة لفهم الذات بالعربية والإنجليزية. المحتوى نفسه متاح للجميع: اقرأ ما تشاء وبالترتيب الذي تريد، دون تسجيل أو أسئلة شخصية.

**افتح التطبيق:** https://amrhafez.github.io/my-map-app/

## المواضيع
| الموضوع | الأقسام | ماذا ستجد؟ |
|---|---|---|
| الهوية: اعرف نفسك | 8 | طبقات الهوية، والاحتياجات، والقيم، ونقاط القوة، والمشاعر، وأنماط الشخصية |
| أنا والآخرون | 8 | أساليب الكلام، والتواصل اللاعنيف، والإصغاء، والتعلّق، وإدارة الخلاف |
| النمو والازدهار | 11 | الأهداف والعادات، وعلم النفس الإيجابي، وأركان الرفاه |
| العطاء المسؤول | 23 | الدوائر الثلاث، والحدود اللطيفة، وطلب المساعدة، والوقاية من الاحتراق |
| الفقد والصمود | 5 | مراحل الفقد، وما تقوله أبحاث الحزن الحديثة، والعناية بالنفس وبمن نساندهم |

في الأقسام العملية أمثلة تطبيقية جاهزة توضّح كيف تُستخدم الأداة. وفي التطبيق بحث في المكتبة، ووضع داكن، وأحجام نص مختلفة.

## الخصوصية
لا يحفظ التطبيق أي إجابات. يُحفظ في متصفح الزائر فقط تقدّم القراءة وإعدادات العرض، ولا يُرسل شيء إلى أي مكان.

## التصميم
ملف التصميم في [Figma](https://www.figma.com/design/4YdV1h8VzZ75xVY8y88SM7) (صفحة Thumbnail لصورة المعاينة 1200x630).

## تنبيه
محتوى تعليمي للقراءة والتأمل الذاتي، مبني على أبحاث منشورة ومراجعه داخل التطبيق. ليس أداة تشخيص نفسي ولا بديلًا عن مختص.
